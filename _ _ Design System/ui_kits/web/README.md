# БИЕ ДААЛТ — Web App UI Kit

Interactive recreation of the БИЕ ДААЛТ student grade management web application.

## Screens
- **Login** — Teacher/Student tabs, Google OAuth button
- **Dashboard** — Stats, student grid with search/filter, grade distribution chart
- **Student Detail** — Hero with avg score, bar chart, grade table with letter badges
- **Add Student** — Form with grade input per subject

## Components
- `Components.jsx` — Icons, Button, Badge, Toast, Header, StatCard, Modal
- `Dashboard.jsx` — Dashboard screen with student cards, filters, charts
- `StudentDetail.jsx` — Detail view with Recharts bar chart
- `Login.jsx` — Auth page with two-panel layout

## Usage
Open `index.html` for the full interactive prototype.
